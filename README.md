# GTAV iOS Port

Source files for the iOS port, copied from `celiocasttro/gtav-recomp`.

This repository contains project source and build tooling only. It must not contain GTA V disc images, title updates, generated game code, game data, translated game shaders, or a built `GTAV.ipa`. Those outputs must be generated locally from the owner's legally obtained game files and must not be redistributed.

See `docs/IOS_PORT.md` for the iOS architecture and build flow. The supported release flow uses the official `gtav-recomp` release package and its `--iphone` build path; the source scripts here are for development and packaging, not a replacement for the bundled release toolchain.
